# STYLEVERSE — Your World of Fashion

A responsive, editorial-style fashion storefront built with plain HTML, CSS, and
JavaScript. No framework, package installation, or build step is required.

## Run locally

From the project directory, start a local static server:

```sh
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Storefront features

- Responsive navigation, animated hero, collection filters, and sortable product
  cards.
- Interactive size and colour options, wishlists, product previews, and a cart
  drawer with quantity controls and a subtotal.
- Newsletter sign-up, review highlights, an Instagram-inspired gallery, and
  accessible labels and reduced-motion support.
- Product photography is loaded from Unsplash.

Cart, wishlist, and sign-up interactions are front-end demonstrations; no
payment provider, inventory service, or mailing-list backend is configured.
